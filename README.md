# Resume JD Tailor Agent

An Agentic AI system for resume and job description analysis,
matching, tailoring, and interview preparation.

## Planned Features

- Resume PDF/DOCX upload
- Job Description PDF/DOCX upload
- JD analysis
- Resume analysis
- Resume-JD matching
- Skill gap analysis
- Resume bullet rewriting
- Cover letter generation
- Critic agent
- Revision agent
- Interview preparation

## Tech Stack

- Python
- FastAPI
- LLM API
- HTML/CSS/JavaScript
- SQLite/PostgreSQL
- Git/GitHub
